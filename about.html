About Donor Connect

Donor Connect helps link blood donors and patients quickly through an easy online network. Users can register as donors or submit requests for blood. Submissions are stored in a Google Sheet via a Google Apps Script web app so organizers can manage matches and contact donors fast.

This lightweight project was built for a hackathon and is optimized for quick deployment on GitHub Pages.
